# Neo Wave Analyzer

An automated Neo Wave Analysis & Pattern Recognition System designed for High-Precision Market Predictions (NAS100, US30, XAUUSD).

## System Architecture

- **`backend/`**: Python Engine (FastAPI, Pandas, NumPy, MT5 API) for Monomove Isolation, Fib Time/Price Calculations & Pattern Rules.
- **`frontend/`**: React + TradingView Lightweight Charts UI for Live Pattern Visualization.

## Core Modules
1. Monomove Vector Extraction Engine
2. Fibonacci Time & Price Ratio Matrix Calculator
3. Neo Wave Pattern Validation Rule Engine
